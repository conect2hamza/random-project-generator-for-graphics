What you are actually looking at

The markup, the stylesheet and the front-end JavaScript are the plugin's shipped files, unmodified. Only the network layer is replaced: the PHP generator and brief renderer are ported to JavaScript so the page can run on its own, and the port is checked against the PHP across 349 briefs — every field and every byte of rendered markup matches.

Try Generate another, then the arrow beside it for same industry, harder and the rest. Share project link copies a URL that rebuilds this exact brief for somebody else, because every brief is reproducible from its seed — the same mechanism behind the daily challenge. Exports really do download: PDF is written directly, so its text stays selectable rather than being a screenshot.
